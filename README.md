# Proyecto Urban Grocers 

Este proyecto contiene la automatización de 9 pruebas que evaluan la funcionalidad 
del campo **name** en la solicitud de creación de un kit de productos para un nuevo usuario
en la aplicación Urban Grocers. Aspectos importantes a considerar:

-Necesitas tener instalados los paquetes pytest y request para ejecutar las pruebas.

-Ejecuta todas las pruebas con el comando pytest
